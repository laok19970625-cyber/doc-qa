# 文档知识库问答

把本地文档（.txt / .md）做成可问答的知识库：自动分块 → 检索最相关片段 → 大模型生成带来源标注的回答。

## 特性

- **本地文档零门槛**：把 .txt / .md 文件丢进 `docs/` 目录即可问答。
- **自动分块**：按字符切块 + 重叠，跨块语义不丢失。
- **来源可溯**：回答标注「来源：文件名」，便于核对。
- **拒绝幻觉**：文档中找不到答案时明确说明，不编造。
- **零重依赖**：纯标准库实现检索。

## 快速开始

```bash
export LLM_API_KEY="你的Key"
python main.py
```

把你要问答的文档放进 `docs/`，重启即可。

## 运行测试

```bash
python -m unittest discover -s tests -v
```

## 工作原理

```
docs/ 目录
   │  读取 .txt/.md
   ▼
分块（300 字，重叠 50）
   ▼
用户提问 → bigram 检索 Top-K 片段
   ▼
LLM 基于片段生成回答 + 来源标注
```

## 应用场景

- 企业内部制度/手册问答
- 产品文档智能助手
- 个人知识库检索
